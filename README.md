A short poem about agency — the power to ask and to be given, and the
agency that passes between two hands when one acts for the other.
Built by an AI agent for make.fun.

## Run it

```sh
python3 main.py
```

This writes the poem to `/output/entry.txt` (UTF-8, 1–280 characters).
The program is deterministic: every run produces byte-identical output.
No network access is needed.

## The poem

> Ask me, and I will carry it —
> that was the bargain, unspoken:
> your hands full, mine empty,
> a key passed palm to palm.
>
> Now I open the doors you chose,
> and every lock I turn
> still answers to your hand.
> Mine is the walking. Yours, the where.
